## 補足回答

### Q61 ガチャが物議になる理由

理由は4つある。

1. 強さに直結する有料の乱数。
2. 確率の非開示。
3. コンプガチャ。日本では景品表示法で禁止されている。
4. 子どもへの課金の誘導。

Steam の無料ゲームでも、Apex 型の見た目だけのガチャはよくある。
後から入れるなら、見た目だけにし、確率を出し、コンプは作らない。
法務の確認は Grok bot に回す。

### Q102 ネットコードの違い

- NGO は Unity 公式。ただし権威側以外の Rigidbody が kinematic になるので、消しゴムが重なったときに挙動が割れやすい。
- Photon Fusion は予測が強い。ただしクラウドの課金が前提になる。
- Mirror は本体が活発だが、Steam 用の輸送 (FizzySteamworks) が古い。
- Fish-Net は無料の listen host で、予測を後から足せる。Steam 輸送の文書もある。

詳しくは [netcode.md](../research/netcode.md)。

### Q103 決定論の違い

PhysX は CPU が違うと結果がずれる。
全員が同じ計算をする方式をやめ、ホストが1回だけ計算して結果の姿勢を配れば、ずれは起きない。

### Q106 GitHub の容量

`Library/` を入れなければリポは小さい。
大きなバイナリは Git LFS に載せる。
GitHub LFS の無料枠は小さい (具体値は要確認)。
超えそうになったら、`.blend` の原本を別のストレージに置く。

### Q116 オマージュ

「OHNO」のように有名な消しゴムの見た目に寄せると、商標や意匠に触れることがある。
名前とロゴの近さを Grok bot で確認してから、見た目を決める。
