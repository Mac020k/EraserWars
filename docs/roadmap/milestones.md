## フェーズと完了条件

### P0 土台 (2026-11 後半)

- `.gitignore` を直し、git-lfs を入れる ([ADR-0004](../decisions/ADR-0004-gitignore-lfs.md))。
- テンプレートの `TutorialInfo/` と `Readme.asset` を消し、productName を `KeshipinWars` にする。
- `docs/` と英語の README を作る。
- `Assets/_Project` と asmdef を作り、パッケージを足す (Test Framework、Cinemachine 3。Localization / ProBuilder / Multiplayer Play Mode は Unity 6000.6.9f1 で CS0619 になるため保留)。
- `tools/run-tests.ps1` を作る。
- UI モックを2案作って見せる ([ADR-0006](../decisions/ADR-0006-ui-direction.md))。

完了条件。別フォルダに clone した状態から Unity で開けて、空のテストが `run-tests.ps1` で緑になる。

### P1 物理の縦切り、カードなし (2026-12)

- スケールを1単位=1m、10cm、1cm の3案で比べ、ADR に残す ([ADR-0007](../decisions/ADR-0007-physics-scale.md))。
- Core の reducer と EditMode テスト。ライフの減少、自爆、パス、時間切れ、同じラウンドの同順位、後攻が残っているあいだの続行。
- 2×2 の机、直方体の消しゴム、定位置4つ、落下判定、静止判定。
- 2〜4人のホットシート。ストック3、復帰、1ボタンの即再戦、デバッグ表示。
- Fish-Net 4.x を 6000.6.9f1 に入れる1日スパイク ([ADR-0008](../decisions/ADR-0008-fishnet-spike.md))。

完了条件。

- PlayMode テスト「定位置Aから既知の力積で弾くと、Bが8秒以内に落ちる」が緑。
- 自爆ショットで自分のライフが1減る。
- オペレータが2人と4人で3試合ずつ遊び、`playtests/` に記録する。
- 起動から最初の落下まで3分以内。

### P2 弾きの手応え (2027-01 前半)

- ブレと力点スピン。数値は `FlickTuning` に出す ([04_flick.md](../gdd/04_flick.md))。
- Cinemachine の斜め軌道カメラ、俯瞰 (Tab)、クローズアップ (C)、シミュレーション中の追従。
- ヒットストップ、見た目だけの揺れ、縁際のスロー、0.8秒以内の落下演出、実録の SE。
- マウスとコントローラの入力。

完了条件。ブレの中心で離した場合と端で離した場合の到達角の差が、PlayMode テストで設計値どおり。オペレータが「長く引くほど怖い」と感じたかを記録する。

### P3 ルールの比較 (2027-01 後半)

- ストック戦とポイント戦 (8ラウンド) を `RuleSet` で切り替える。
- 各ルールで5試合以上遊び、試合時間、逆転の回数、ワンパンで終わった回数を試合ログから集計する。

完了条件。試合時間の中央値が5〜15分に入るルールが決まり、ADR に残る。

### P4 カードとキャラ4体 (2027-02)

- `EraserDefinition`、`CharacterDefinition`、`CardDefinition`、`StageDefinition`、`RuleSet` の ScriptableObject と CSV 取込。
- デッキのルール。共通カード12枚。キャラ4体 ([07_cards.md](../gdd/07_cards.md)、[06_characters.md](../gdd/06_characters.md))。

完了条件。

- EditMode テストで全カードの効果と持続ターン切れが通る。
- 同名上限とコスト超過のデッキは保存できない。
- 4人卓で、カードありの試合時間が P3 の目標内に収まる。

### P5 コンテンツ (2027-03〜04)

- キャラ8体 (外国人2体を含む)、ステージ6つ、共通カード40枚、固有カード16枚。
- 図鑑とアンロック。
- URP のトゥーンシェーダ。
- Blender の導入と、OpenCV の前処理。

### P6 オンライン (2027-05 前半)

- Tugboat で、ホットシートと同じコマンドの経路。
- Steamworks.NET、ロビーの招待、FishySteamworks。
- 切断の30秒待ちと強制スキップ。

完了条件。2台の PC (または2つの Steam アカウント) で4人戦を1試合やりきり、両方の試合ログの最終状態ハッシュが一致する。

### P7 モード (2027-05 後半〜07 前半)

CPU、秘密部屋、マッチメイキング、1対1ランク、ストーリー、アドベンチャー、リプレイ、成長要素 ([08_modes.md](../gdd/08_modes.md))。

### P8 Steam 出荷 (2026-12 開始、2027-08 公開)

手順は [steam-operator-checklist.md](steam-operator-checklist.md)。

- 2027-04〜06。Steam Playtest。人が少ない時間帯でも CPU 戦で遊べるようにしておく。
- 2027-06。Next Fest の6月回があれば出る。日程は通例からの推測で、要確認 ([steam.md](../research/steam.md))。
- 2027-07。ビルド審査と Content Survey。AI の利用を開示する。
- 2027-08。公開。

## リスク

- 1人で、予算10万円で、2027年8月。最大のリスクは日程。削減ゲートで調整する。
- Fish-Net と Unity 6000.6 の相性は未検証。P1-5 で先に確かめる。
- 小さな物体の物理はすり抜けや跳ねが起きやすい。P1-1 のスケール試作で先に潰す。
- 無料の対戦ゲームは人が集まらないと遊べない。CPU 戦とホットシートを常に残す。
- listen host には、ホストのチートと離脱がある。ランクだけ結果照合で守り、カジュアルは UI で注意を出す。
- keshipin.jp が近い名前を使っている。商標の確認は遅くとも2027年3月までに行う。
