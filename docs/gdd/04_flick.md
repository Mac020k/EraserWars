# 04 弾き

弾きはこのゲームの手応えの中心である。
数値は P2 の初期値で、`FlickTuning` という ScriptableObject に出し、プレイ中に調整する。
式は `EraserWars.Core.FlickMath` にあり、UnityEngine に依存しない。

## 入力

ホットシートでは、画面のどこをドラッグしても今の手番の消しゴムを弾ける。
対象は `MatchDirector.TryGetCurrentEraser` が返す消しゴムである。
`Phase.MatchEnd` と `Phase.Simulating` ではドラッグを始めない。

押してから離すまでを `TrackpadGesture` として測り、`FlickCommand` を1回に変換する。
`DragLength01` は画面上のピクセル長を `maxDragPixels` (初期値 180) で割った値で、0 から 1 に切る。
向きは、消しゴムの高さにある水平面へ押した点と離した点を投影して決める。
引き方向は `pressWorld - releaseWorld` の XZ である。
投影できないときは、カメラの右方向と前方向へ画面差分を落として XZ の向きにする。
指を手前に引くと、消しゴムは画面の奥へ飛ぶ。
押した点が今の消しゴムに当たったとき、そのローカル XZ を `ContactOffset` にする。
当たらないドラッグは中心 (0, 0) のままである。
`DragLength01` が 0.05 未満ならコマンドは出さない。ターンも消費しない。
押しているあいだ、消しゴムから引きの向きに線を出す。
線の長さは `DragLength01` に比例し、色はプレイヤー色である。
この線はブレでは動かない。強さは長さだけが示す。
ブレの端は白い扇で、その場に留まる。
離した瞬間に飛ぶ向きは、扇の中を往復する黒い矢印である。
離したときと、キャンセルしたときに線を消す。

### マウス (主)

- 左ボタンを押したまま引き、離すと弾く。消しゴムのメッシュに当てる必要はない。
- 左上のデバッグパネル (画面座標 `Rect(12, 12, 460, 280)`) 上で押したときは弾かない。
- パスは Space か Pass ボタンである。ドラッグ中の Space は狙い線を消してからパスする。
- 右ボタンのドラッグはカメラの回転のままにする。ホイールでズームする。

`FlickApplier.jMax` の初期値は 0.24 である (フル引きの飛距離を約2倍にするため、以前の 0.12 から倍にした)。
弾いた直後に `linearVelocity` が 3.6 m/s を超えたら、その長さへ切り詰める。
`EraserBody.speed` の初期値は 0.65 である。
`linearDamping` は `1.5 / speed` になり、`angularDamping` は 1.2 である。
フル引きは机を大きく横断できる。追従しやすさはカメラのシミュレーション追従とモーショントレイルで補う。

## 消しゴム同士の衝突

PhysX の解決のあと、接触法線方向だけを教科書の 1D 衝突で書き直す。

\[
v_1' = \frac{m_1 v_1 + m_2 v_2 - m_2 e (v_1 - v_2)}{m_1 + m_2}, \quad
v_2' = \frac{m_1 v_1 + m_2 v_2 + m_1 e (v_1 - v_2)}{m_1 + m_2}
\]

復元係数 `e` の既定は 1.0。等質量なら法線速度を交換する (当てた側が止まり、当てられた側が飛ぶ)。
至近距離の弱い接触でも、接近速度を最低 2.0 m/s、飛び出しを最低 2.4 m/s に底上げする。ゲームとして当てられた側が必ず飛ぶようにするためである。
既に密着しているペアは `OnCollisionEnter` が再発火しないので、`OnCollisionStay` でも同じ解決を走らせる。
接触法線は机平面 (XZ) に投影する。密着 Stay で上がりがちな垂直法線のままだと、Y 方向の飛び出しをその直後に打ち消してしまい、当てられた側がほとんど動かない。
実装は `CollisionMath` と `EraserCollisionRelay`。

### コントローラ

`StickFlick.TryCommand` が左スティックを `FlickCommand` にする。ホットシートでは `HotseatFlickInput` がそれを出す。

- 左スティックは飛ぶ向きである。上はカメラの水平前方、右はカメラの右。
- 右トリガー、左トリガー、または南ボタン (Xbox の A、PlayStation の Cross) を押しているあいだ狙い線が出る。離した瞬間のスティックで弾く。
- 倒し量はデッドゾーン 0.2 を引いて 0 から 1 にする。0.05 未満はコマンドを出さない。
- 力点は中心 (0, 0) のまま。端のスピンは、マウスで消しゴムに当てたときだけ付く。
- 東ボタン (Xbox の B、PlayStation の Circle) はパスである。狙い中なら線を消してからパスする。
- 右スティックのカメラ回転は、この入力には入れていない。

## 弾きのコマンド

入力は `FlickCommand` にまとめる。ホットシートでもネットでも同じ形を使う。

| 項目 | 意味 |
| --- | --- |
| `Player` | 弾く人 |
| `Direction` | 狙いの向き (机の平面上) |
| `DragLength01` | ドラッグ長を0〜1に正規化した値 `L` |
| `ContactOffset` | 上面の力点。(-1..1, -1..1) |
| `ReleaseTime` | ドラッグを始めてから離すまでの秒数 `t` |

## 強さ

力積は次の式で決める。

\[ J = \mathrm{power} \cdot J_{\max} \cdot L^{1.5} \]

`power` は消しゴムのパワー。
指数を1より大きくしたのは、短いドラッグで細かく狙えるようにするため。

## ブレ

狙いの角度は時間で左右に揺れる。

\[ \theta(t) = \theta_{\mathrm{aim}} + A \sin(2\pi f t) \]

\[ A = A_0 \cdot L^2 \cdot \mathrm{sizeFactor}, \qquad f = f_0 + f_1 \cdot L \cdot \mathrm{sizeFactor} \]

- 長く引くほど、ブレは大きく速くなる (Q30)。
- 大きい消しゴムは `sizeFactor` が大きく、ブレが大きく速い (Q41)。
- ブレは矢印として常に見せる。離した瞬間の `θ` で確定する。
- 乱数は使わない (Q37)。うまい人はブレの中心で離せる。

これがリスクとリターンの核になる。強く弾けば落としやすいが、狙いが外れて自分が飛ぶ。

## スピン

- 力点 `ContactOffset` の XZ で `AddForceAtPosition` をかける。高さは重心に合わせ、中心打ちが倒れないようにする。中心から外すほどヨーが大きくなる (Q31)。
- ヨーは机平面での `r × J` である。押し方向と垂直な端が最大で、力点を通る押しは 0 である。
- `FlickTuning.SpinGain` の初期値は 1 である。1 のときは力点の位置だけで回り、1 より大きいと同じ力点でヨーだけをその倍率にする。
- スピンは必須の技で、上級者だけのものにはしない。

## 滑り

スピードは `linearDamping` の逆数として効かせる。値が高いほど遠くまで滑る。

## 予測線

- 最初の衝突点まで描く。
- 上位ランクでは出さない (Q33)。
- 先の衝突まで見せるのはカードの役にする (予言ノート)。
- ホットシートの狙い線は強さとブレの読みである。衝突点まではまだ描かない。

## 落下の判定

次のどちらかで落下とする。

1. 床のキルゾーンに触れた。
2. 机のコライダーと接していないまま、重心が机の天面より消しゴム1個分の高さ以上下にある。

縁で引っかかっている間は落下にしない (Q20、Q23)。

## 静止の判定

- 全消しゴムの速度が ε 未満の状態が0.3秒続いたら静止とする。
- シミュレーションは最大8秒で打ち切る。

## ヒットストップと演出

- ヒットストップは `Physics.simulationMode = Script` で物理の歩みを止めて作る。
- 長さは衝撃の大きさに比例させ、2〜10フレームに収める。1ショットの合計は30フレームまで。
- 揺らすのは見た目の子メッシュだけ。Rigidbody は動かさない。
- 縁際のスローは、2フレームに1回だけ `Simulate` を呼んで作る。
- 落下演出は0.8秒以内。落ちる途中で消しゴム同士が当たったら、スマブラ風の撃墜演出を出す (Q21)。

## 物理の設定

| 項目 | 値 |
| --- | --- |
| 固定 dt | 0.01秒 |
| 消しゴムの衝突判定 | ContinuousDynamic |
| Solver | Projected Gauss Seidel |
| Enhanced Determinism | オン |
| 世界スケール | 仮に1単位=10cm ([ADR-0007](../decisions/ADR-0007-physics-scale.md)) |

実寸の消しゴムは約43×17×11mm (推測)、机は600×400mm 前後。

## 確かめること

- P2 の完了条件。ブレの中心で離した場合と端で離した場合の到達角の差が、PlayMode テストで設計値どおりになる。
- オペレータが「長く引くほど怖い」と感じたかを記録する。
