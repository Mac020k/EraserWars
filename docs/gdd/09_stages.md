# 09 ステージ

## 方針

- 発売時は6つ (Q72)。
- ユーザー作成ステージは作らない (Q73)。
- 障害物は教室以外にだけ置く (Q22)。
- 教室はそこそこリアルにする (Q87)。

筆箱、教科書、定規のような教室の物を候補にする (推測)。

## 教室 (最初のステージ)

- 机4つを 2×2 の正方形に並べる (Q107)。1台は600×400mm 前後。
- 4か所の定位置からランダムに置く (Q27)。
- 机の継ぎ目に引っかかる挙動は味として残す (Q23)。
- 机の下に床のキルゾーンを置く。
- Editor の `EraserWars > Build Classroom Casual Scene` が `Assets/Scenes/Classroom_Casual.unity` を作る。

## 定義

`StageDefinition` が持つ。

- シーン。
- 定位置4つ。
- 机の物理マテリアル。
- 障害物の配置。

カードの `PlaceDeskObject` (定規ガード、消しカス) は、ステージの障害物と同じ仕組みで机に物を置く。

## 確かめること

- P1 で、教室の卓で2人と4人を3試合ずつ遊び、継ぎ目の引っかかりが「味」に見えるかを記録する。
- P5 で、障害物のあるステージでも試合時間が5〜15分に収まるかを記録する。
