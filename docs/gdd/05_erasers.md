# 05 消しゴム

## 方針

- 形は実物寄り。盛るのは固有カードと演出 (Q13)。
- 最初は直方体だけ。変形消しゴムは後で足す (Q40)。
- 実在の消しゴムにはオマージュとして似せてよい。名前とロゴの近さは確認する (Q116)。
- 耐久値はない。カードで付けたシールドと武器は壊れる (Q39)。

## パラメータ

`EraserDefinition` が持つ (Q38、Q53)。

| 項目 | 効き方 |
| --- | --- |
| 質量 | 当たったときに押し負けにくい |
| 摩擦 | 止まりやすさ、縁での粘り |
| 反発 | 当たったときの跳ね返り |
| サイズ | 当たりやすさと、ブレの `sizeFactor` |
| 重心 | 転びやすさ、スピンのかかり方 |
| パワー | 力積の倍率 ([04_flick.md](04_flick.md)) |
| スピード | `linearDamping` の逆数。高いほど遠くまで滑る |
| デッキコスト上限 | 共通カードの合計コストの上限 |
| 手札上限 | 平均3枚 |
| パッシブ | 消しゴムに付く能力 (Q47) |

## 大きいほど強い問題

大きく重い消しゴムは当たり負けしない。
釣り合いは2つの値で取る (Q41)。

- スピードを下げ、滑りにくくする。
- ブレを大きく速くする。

## 状態変化

カバーの有無のような状態変化は、一部の消しゴムだけに置く。
変えるのは固有カード (Q42)。

## キャラとの対応

- 最初はキャラと消しゴムが1対1 (Q43)。
- 性能と見た目はセットで、エアライドの乗り物のように扱う (Q44)。
- 1キャラに複数の消しゴムを持たせるのは後で足す。パッシブを消しゴム側に置くのはこのため (Q47)。
