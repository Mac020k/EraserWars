# 08 モード

## 発売時に揃えるモード

Q65 で決めた6つ。作る時期はフェーズで分ける ([milestones.md](../roadmap/milestones.md))。

| モード | 中身 | 時期 |
| --- | --- | --- |
| カジュアル (教室) | 2〜4人のホットシート。動作確認もここで行う | P1 |
| CPU 戦 | 空いた席を CPU で埋める | P7 |
| オンラインマッチ | Steam ロビーをモードと地域で検索する | P7 |
| 秘密部屋 | 合言葉で入る。ルールをスマブラ並みに変えられる | P7 |
| ガチランク | 1対1。予測線なし。結果を照合してレートを更新する | P7 |
| ストーリー | ノベル形式の章と CPU 戦で、キャラを解放する | P7 |
| アドベンチャー | 学マス型のローグライク。デッキを育てる | P7 |

最初のビルドでは、ストーリーをモード選択メニューの枠だけにする (Q11)。

## カジュアル (教室)

- 最初の縦切り。カードなし、物理だけで遊べることを先に確かめる (Q110)。
- 人間同士のホットシート (Q109)。手番ごとに画面を切り替える。画面分割はしない (Q68)。
- デバッグ表示を常設する。質量、速度、接触点、フェーズを出す (Q111)。
- 1ボタンで即再戦 (Q112)。

## CPU 戦

- 候補ショットを N 本、別の PhysicsScene で試算して点数を付け、いちばん良いものを選ぶ。
- 難易度は N とブレの再現度で変える。弱い CPU はブレの端で離すことがある。
- 人が少ない時間帯でも遊べるように、Playtest の時点で入れておく。

## 秘密部屋

- 合言葉で入る。
- 変えられるのは、ストック数、制限時間、予測線、乱戦など (Q70)。
- 乱戦 (同時に弾く) はここで選ぶ (Q24)。

## ガチランク

- 1対1 (Q2)。
- 予測線なし (Q33)。
- 結果は Cloudflare Workers と D1 に置き、両者の結果が一致したときだけレートを更新する ([10_online.md](10_online.md))。
- 禁止カードはシーズンごとに変える (Q60)。

## ストーリー

- 小学生が主役のギャグ。ダンボール戦機やデュエル・マスターズの空気 (Q8)。
- ノベル形式の章と CPU 戦を交互に進め、キャラを解放する。
- 全8章を予定する。4月末の削減ゲートで、4章で出して残りを無料アップデートに回すかを決める。

## アドベンチャー

- 学マス型のローグライク。試合を重ねてデッキを育てる (Q52)。
- 1キャラに複数の消しゴムを持たせる仕組みも、ここで試す (Q43)。

## チュートリアル

- 文字の説明から始めない。起動したら教室の卓ですぐ弾かせる ([sakurai.md](../research/sakurai.md))。
- 起動から最初の落下まで3分以内。
- カードは数手後に1枚ずつ見せる。
