# 03 卓のルール

## 卓

- 2〜4人の可変卓 (Q108)。空いた席は CPU で埋められる。
- 教室の机4つを 2×2 の正方形に並べる (Q107)。
- 初期配置は4か所の定位置からランダム (Q27)。
- 最初の教室ステージに障害物は置かない (Q22)。
- 机の継ぎ目に引っかかる挙動は味として残す (Q23)。

## 勝ち方

`RuleSet` が勝利条件を持つ。本線はストック戦で、ポイント戦は P3 で比べる (Q16)。

### ストック戦 (本線)

- 初期ストックは3。
- 落ちたらストック-1。相手に落とされても、自爆でも同じ (Q17)。
- ストックが0になったら脱落する。脱落したラウンドを記録する。
- 最後の1人が勝つ。

### ポイント戦 (比較用)

- 8ラウンドで終わる。
- 相手が落ちたら、最後に触れた者に+1。
- 自爆は-1。
- 合計点で順位を決める。

P3 で各ルールを5試合以上遊び、試合時間、逆転の回数、ワンパンで終わった回数を比べる。
試合時間の中央値が5〜15分に入るルールを本線にする。

## 手番とラウンド

- 相手を落としても連続手番はない (Q19)。
- パスできる (Q26)。
- 1ターンに制限時間がある。既定20秒。0でオフ (Q25)。
- 時間切れは自動パス。
- 1ラウンドは全員が1手ずつ指すこと。

## 同時落下と順位 (Q18 の解釈)

- 勝敗はラウンドの終わりに判定する。
- 同じラウンドで落ちて脱落した者は同順位。
- 後攻に手番が残っていれば、試合は続く。後攻が落ちても、同点以上を取る機会があるから。
- ラウンドの終わりに生き残りが1人以下なら、試合が終わる。0人なら、最後のラウンドで脱落した全員が同率1位になる (推測。P1 で遊んで確かめる)。

## 落下の判定

PhysX 上で完全に落ちたときだけ落下とする (Q20)。
式は [04_flick.md](04_flick.md) にある。

## 復帰

落ちてもストックが残っていれば、自分の次の手番の始めに、空いた定位置へ置く。

## 切断

切断したプレイヤーは30秒待ち、その後は毎ターン強制スキップする (Q78)。
ホストが抜けたら試合は終わる ([10_online.md](10_online.md))。

## 乱戦 (特殊モード)

全員が同時に弾く乱戦は、通常ルールに入れない。
秘密部屋のルール改変で選べる特殊モードにする (Q24、Q70)。

## ルール設定の範囲

`RuleSet` は次を持つ。

| 項目 | 既定 | 変更できる場所 |
| --- | --- | --- |
| 勝利条件 | `Stock(3)` | 秘密部屋。ポイント戦は `Points(8)` |
| 制限時間 | 20秒 | 秘密部屋で0 (オフ) まで |
| 予測線 | あり | 上位ランクではなし (Q33) |
| 乱戦 | なし | 秘密部屋 |
