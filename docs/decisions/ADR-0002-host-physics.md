# ADR-0002 ホストだけが物理を計算する

- 状態: Accepted
- 日付: 2026-11-14
- 関連: Q37、Q103、[netcode.md](../research/netcode.md)

## 文脈

PhysX は、同じマシンと同じビルドで Enhanced Determinism をオンにしたときだけ決定論的になる。
CPU ベンダーや x86 と ARM の間では結果が変わる ([sakurai.md](../research/sakurai.md) の Unity Discussions)。
全員が同じ入力から自分で物理を回すと、消しゴムの止まる位置がずれる。

## 選択肢

1. 全員が同じ物理を回す (ロックステップ)。CPU ごとにずれる。
2. クライアント権威。自分の消しゴムを自分で動かす。持ち主の違う消しゴムが1つの衝突解決を共有できない。
3. 決定論的ロールバック。Unity の GhostObject 物理は 6000.7 以降で、Enhanced Determinism もビット単位の一致を保証しない。Photon Quantum は独自の物理で、作り直しになる。
4. ホストだけが計算して、結果の姿勢を配る。

## 決定

ホストだけが PhysX を回す。

- クライアントは入力 (`FlickCommand`、カード、パス) を送り、姿勢を受け取る。
- 静止したら、ホストが静止姿勢を信頼性ありで1回送る。
- 乱数は使わない (Q37)。ブレは `ReleaseTime` から決まる周期関数にする。
- 物理の設定は固定 dt 0.01秒、ContinuousDynamic、Projected Gauss Seidel、Enhanced Determinism オン。

## 結果

- PhysX のシーンは1つだけなので、ずれが起きない。
- ホストの弾きには遅延がなく、クライアントには往復の遅延がある。不公平に感じたら、ホストの消しゴムも同じ姿勢バッファから描く。
- 滑っている最中に質量や摩擦を変えるカードは、ホストだけで実行する。
- リプレイは、イベント列と各ターンの静止姿勢の記録になる。再シミュレーションには頼らない。
- CPU 戦の試算は別の PhysicsScene で回すので、本番の結果に影響しない。
