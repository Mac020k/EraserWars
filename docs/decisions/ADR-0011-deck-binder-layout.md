# ADR-0011 デッキ構築画面のバインダー構成

- 状態: Accepted
- 日付: 2026-11-18
- 関連: [ADR-0010](ADR-0010-character-card-face-crops.md), `docs/prototypes/deck-proposal-B-binder.jpg`

## 文脈

旧デッキ画面は、キャラクター一覧とコモン一覧が縦横に混在し、スクロール方向が二つあった。
プロトタイプ案 B (バインダー) の構造に寄せて作り直した。画像との完全一致は求めない。

## 決定

| 領域 | 内容 |
| --- | --- |
| 左ページ | 「プレイヤー Pn」リボン、丸い顔、名前、タイプのピル、ステータス表 (質量 / コスト上限 / 得意・苦手)、紹介文、とくぎ 2 枚、キャラ顔チップの横ストリップ |
| 右ページ | 見出しと状態行、プリセット 1-5、ファミリーフィルタ、2 列のカードグリッド、コストバーと保存のフッタ |
| カードセル | 顔 (コスト宝石付き)、名前、ファミリーバッジ、1 行説明、－ 枚数 ＋、チェック印 |

## 判断

- 説明文を持たないカード定義なので、1 行説明は `CardGlance.LabelJa` と回数 / クールタイム / 継続ターンから組み立てる。
- プロトタイプのレアリティバッジは、レアリティ欄が無いためファミリーバッジで置き換えた。
- 追加と削除は、1 タップの誤操作を避けるため 44px 以上の明示的な ＋ / － ボタンにした。
- P1-P4 の席タブは上部に残した。キャラの切り替えは顔チップで行う。
- フィルタは表示だけを絞る。デッキの内容と保存の規則 (`DeckRules`、`DeckPresets`、`DeckBudget`) には触れていない。
- カードグリッドは縦スクロールのみ。追加と削除でグリッドを作り直すが、スクロール位置は保持する。

## 追記: ハンドブック外観

- 他の画面と共通の紺色の板 (`.destination-page`) が背景に見えていたため、デッキ画面ではパネル自体をピンクの表紙にした。
- ヘッダ (もどる / タイトル) と P1-P4 の席タブを表紙の上に置き、タブはフォルダ型にした。
- ページは罫線入りの紙 (`UiImageUtil.ApplyRuledPaper`) にし、中央に橙色のコイルリングを重ねた。
- 背景色は `StartMenuController.DestinationBackground` がインラインで上書きするため、表紙色はそこで指定する。

## 検証

- EditMode テスト 250 件が成功。グリッドの 1 コモン 1 セル、枚数とチェック印、ファミリーフィルタを追加した。
- Game ビューで P1-P2 の切り替え、キャラ切り替え、コスト上限の警告、フィルタを確認した。
