# ADR-0009 スタート画面と教室ビジュアル

- 状態: Accepted
- 日付: 2026-11-15
- 関連: Q8 訂正、Q10、Q87、[ADR-0006](ADR-0006-ui-direction.md)、[11_art-ui-audio.md](../gdd/11_art-ui-audio.md)

## 文脈

オペレータが教室の日本らしさ不足と文字だけの Debug UI を指摘した。
調査後に方向を問い、回答は次のとおり。

| 項目 | 決定 |
| --- | --- |
| 教室トーン | 1C。平成中期リノリウム＋蛍光灯を基本に、木味を少し混ぜる |
| 卓の見せ方 | 2A を更新。寄せ机は **横並び4台** (各約0.6×0.4 m) がステージ。周囲に教室セット |
| 窓の外 | 3C。晴れた校庭の固定1種 |
| UI 経路 | 4A。UI Toolkit でスタート＋開閉メニュー＋アイコンHUD |
| カメラ遮蔽 | 5A を更新。壁・天井は遮った瞬間に **完全非表示** (半透明残しなし) |
| スタート | **6B**。専用フルスクリーンメニューからマッチへ遷移 |
| 教室寸法 | 戦後標準に近い **間口9 m × 奥行7 m × 天井3 m**。窓側4開口/5柱、廊下側高窓＋引き戸、後方に掃除ロッカー |

モック: `docs/prototypes/ui-mock-start-fullscreen-6b.jpg` (採用)、`ui-mock-start-overlay-6a.jpg` (不採用比較用)。

Q8 の「ころころ」は擬態語ではなく **コロコロコミック**。UI／演出の熱量は誌面・デュエマ／ダンボール戦機のホビーバトル感に寄せる。

## 決定

1. 試合前はフルスクリーンの UI Toolkit スタート画面。中央に「マッチ開始」、下段に 2P/4P・デッキ・コレクション・オプションの5タイル。
2. 試合中 HUD は broadcast (ADR-0006) を踏襲しつつ、プレイヤーピルでストックを示す。詳細は開閉メニュー。
3. `ClassroomSceneBuilder` は標準教室寸法と平成記号 (床、緑黒板、掲示板、外窓＋校庭、廊下高窓・扉、掃除ロッカー) を足す。ステージは横並び4机。
4. カメラと机フォーカスの間を遮る壁／天井はレンダラをオフにして完全に消す (コライダは残し、遮蔽検出を継続)。

## 結果

- OnGUI の Hotseat 起動はスタート画面から呼ばれる経路に寄せ、常時 Debug パネル依存を減らす。
- アート方向の誤解 (ころころギャグ) はドキュメントを訂正済み。
