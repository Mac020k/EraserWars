# ADR-0003 発売時は無料+DLC で、有料ガチャなし

- 状態: Accepted
- 日付: 2026-11-14
- 関連: Q7、Q61、Q114、[12_monetization.md](../gdd/12_monetization.md)

## 文脈

オペレータは無料+DLC を選んだ (Q7)。
ガチャも入れたいと答えたうえで、なぜ物議になるかを尋ねた (Q61)。
狙う層には小学生ノスタルと配信者がいて、配信を見る子どもも含まれる (Q3)。
対戦ゲームは人が集まらないと遊べないので、入口は無料にしたい。

## 選択肢

1. 買い切り。入口が狭くなり、オンラインの人数が集まりにくい。
2. 無料+DLC、有料ガチャあり。強さに直結すると物議になる。
3. 無料+DLC、有料ガチャなし。
4. 無料+DLC、見た目だけのガチャ。Apex 型。

## 決定

本体は無料にし、DLC は確定の価格で売る。
発売時のコアに有料の乱数ガチャは入れない。

## 理由

ガチャが物議になる理由は4つある。

1. 強さに直結する有料の乱数。
2. 確率の非開示。
3. コンプガチャ。日本では景品表示法で禁止されている。
4. 子どもへの課金の誘導。

## 結果

- DLC の中身と値付けは P7 までに決める。
- 後から見た目だけのガチャを入れる余地は残す。入れるなら、見た目だけにし、確率を出し、コンプは作らない。法務は Grok bot で確認する。
- 課金なしの宣言はしない (Q114)。
- 通貨とショップは未決 (Q83)。
