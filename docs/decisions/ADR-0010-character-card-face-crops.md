# ADR-0010 キャラクターカードと顔クロップ

- 状態: Accepted
- 日付: 2026-11-18
- 関連: [ADR-0009](ADR-0009-start-screen-and-classroom-look.md)

## 文脈

旧カードは全身立ち絵 (864x1152) を `background-size: 780%` と上端固定で表示していた。
縦横比が崩れ、髪と目の一部しか映らなかった。
オペレータの参考カードに合わせて作り直した。

## 参考カードの仕様

| 項目 | 値 |
| --- | --- |
| 縦横比 | 縦長 0.68 (実装 142x210) |
| 背景 | クリーム rgb(255,250,238) |
| 縁取り | 太い桃色 rgb(255,170,120)、幅の約5%、大きな角丸 |
| 右上 | 菱形のみ (円の台座なし)、白い細縁 |
| 顔 | 幅の約68%の円、黒リング、上寄せ |
| 順序 | 顔 → 学年組 (小) → 名前 (大、姓と名の間に空白) |
| 学校名 | 表示しない |
| 顔の見せ方 | 頭全体と襟。頭幅は円の65-70%、目は上から45%、中央、切れなし |

## 実装

- `tools/bake_faces.py` が立ち絵から 512px 正方形の顔画像を `Assets/Art/Characters/Faces/` に焼く。
- `CharacterDefinition.FacePortrait` に割り当てる。未設定なら `Portrait` に戻る。
- `EraserWars > Import Character Stills` が顔画像の取り込みと割り当てを行う。
- 顔の描画は `UiImageUtil.ApplyFaceCrop` (`background-size: cover`)。
- Collection と席選びは `CharacterTileBuilder` を共有する。
