# Flick input mapping

Mouse is primary. Controller is secondary.

| Action | Mouse / keyboard | Gamepad |
| --- | --- | --- |
| Choose contact + pull | LMB drag back, release | Left stick aims the flight. Hold RT, LT, or South (A / Cross), then release |
| Orbit camera | RMB drag | Right stick, not wired |
| Zoom | Wheel | Not wired on the pad |
| Top-down | Tab | Select, not wired |
| Close-up | C | West (X / Square), not wired |
| Pass | Space | East (B / Circle) |
| Card 1/2/3 | 1 / 2 / 3 | D-pad, not wired |

`HotseatFlickInput` reads the mouse, Space, the left stick, both triggers, South, and East through the Input System devices. A pad flick keeps contact at the center. There is no `.inputactions` asset yet.
