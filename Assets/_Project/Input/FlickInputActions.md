# Flick input mapping

Mouse is primary. Controller is secondary.

| Action | Mouse / keyboard | Gamepad |
| --- | --- | --- |
| Choose contact + pull | LMB on eraser top, drag back, release | Left stick for contact, hold A, pull left stick, release A |
| Orbit camera | RMB drag | Right stick |
| Zoom | Wheel | Triggers |
| Top-down | Tab | Select |
| Close-up | C | X |
| Pass | Space | B |
| Card 1/2/3 | 1 / 2 / 3 | D-pad |

Implemented for hotseat in `HotseatFlickInput`. Full Input System asset wiring is Phase 2.
