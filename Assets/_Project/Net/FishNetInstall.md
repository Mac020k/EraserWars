# Fish-Net install (P1-5 / P6)

Unity Editor must be closed before package install via batchmode.

Suggested path:

1. Add Fish-Net from Asset Store or git URL into `Packages` / `Assets/ThirdParty`.
2. Enable Tugboat for LAN.
3. Later add FishySteamworks + Steamworks.NET.

`HostCommandGate` is ready to validate commands before reducer apply.
